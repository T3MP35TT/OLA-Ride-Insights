# SQL documentation

`sql/01_create_database.sql` and `02_create_tables.sql` create the MySQL database and typed booking table. `03_load_data.sql` describes explicit CSV loading; adjust its column list to the actual profiled headers and local secure-file settings. `04_indexes.sql` covers common filters. `05_data_validation.sql` reconciles row/key counts, statuses and suspicious values. `06_required_business_queries.sql` contains all ten requirement queries. `07_advanced_business_queries.sql` adds KPI, customer, time, payment, vehicle and rating analyses. `08_powerbi_views.sql` exposes grouped metrics. `09_validation_queries.sql` provides reconciliation aggregates.

The identifiers in the scripts match the source workbook. `Canceled_Rides_by_Customer` and `Canceled_Rides_by_Driver` contain reason strings, so ride counts are filtered by exact status and reason categories are grouped separately. Incomplete rides use `Incomplete_Rides = 'Yes'`; `Incomplete` is not a value in the booking-status column. The ten required query statements were executed against an in-memory SQLite-compatible table and reconciled with pandas. In the Streamlit SQL Explorer, the complete source-sized result is returned; the table is a 500-row preview and CSV export contains the full returned result. A 250,000-row ceiling and execution timeout protect custom queries. The MySQL 8 server-specific setup/load scripts remain to be exercised against an installed database.
